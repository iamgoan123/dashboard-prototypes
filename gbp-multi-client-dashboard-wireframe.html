Check before you connect everything

  • Licence: Supermetrics counts each Location as a separate account, and your plan limits how many accounts you can use at once. The licence screen in your Pinterest setup listed 55 accounts, so add up locations across all clients first.
  • Search terms: monthly only, usually available after the month ends, and Google hides low-volume terms.
  • Average star rating: returns nothing when the period has no reviews. Label it "rating for period".
  • Time zones: set the report time zone to the clients' local time, or daily numbers can shift by a day.
  • Refresh: Supermetrics suggests refreshing every 2 to 3 days, so do not promise live numbers.
  • Impressions: Google counts one per user per day, so they will not match Search Console impressions.
  • Old fields: the connector marks post views, photo views, the old search query metrics and followers as deprecated. Skip them if you copy an older template.
  • Field names here follow the Supermetrics field list. Confirm the exact labels, especially the review fields, in the field picker.

Calculated fields

-- Total impressions (confirm the four surface labels)
`Impressions: Search desktop` + `Impressions: Search mobile`
  + `Impressions: Maps desktop` + `Impressions: Maps mobile`

-- Interaction rate
SUM(`Total actions`) / SUM(`Total impressions`)

-- Client (internal rollup only)
-- Easiest: use the Location group or business account
-- dimension if each client has its own.
-- Otherwise map by name, or blend a Location ID to Client
-- Google Sheet, which is easier to maintain:
CASE
  WHEN REGEXP_MATCH(`Location name`, "(?i)^client a") THEN "Client A"
  WHEN REGEXP_MATCH(`Location name`, "(?i)^client b") THEN "Client B"
  ELSE "Unmapped"
END

-- 5-star share (reviews page)
SUM(CASE WHEN `Review star rating` = 5
  THEN `Reviews` ELSE 0 END) / SUM(`Reviews`)
