Pinterest organic dashboard wireframe

Two sources feed the report: the Profile query for account-level trends and the Top pins query for pin-level ranking. Click any block or spec row to link them. Numbers on the canvas are placeholders.

Build order in Looker Studio

  1. Add two Supermetrics data sources on the same Pinterest account, one on the Profile query and one on the Top pins query. Name them so they are easy to tell apart in the field picker.
  2. Create the date range control once and make it report-level so both pages follow it. Set the default to the last 30 days.
  3. Build the scorecards first with a comparison date range turned on, then the trend charts, then the pin table.
  4. On the Top pins source, add the Rank by parameter and the calculated field below, then use that field in the Top 10 bar chart.
  5. Set the pin thumbnail field type to Image and the destination field to URL so the table shows pictures and clickable links.
-- Parameter: rank_by (text, allowed values:
--   Impressions, Saves, Pin clicks, Outbound clicks)
-- Calculated field: Rank metric
CASE
  WHEN rank_by = "Saves" THEN SUM(`Saves`)
  WHEN rank_by = "Pin clicks" THEN SUM(`Pin clicks`)
  WHEN rank_by = "Outbound clicks" THEN SUM(`Outbound clicks`)
  ELSE SUM(`Impressions`)
END

-- Rates, if the query does not return them
Engagement rate    = SUM(`Engagements`) / SUM(`Impressions`)
Pin click rate     = SUM(`Pin clicks`) / SUM(`Impressions`)
Save rate          = SUM(`Saves`) / SUM(`Impressions`)
Outbound click rate = SUM(`Outbound clicks`) / SUM(`Impressions`)

Check before you build

  • Field names above follow the Supermetrics Pinterest Organic field list. Confirm the exact names, and which fields each query exposes, in the field picker. Followers, audience, video and the pin image URL are the ones most likely to differ by account.
  • The Top pins query returns a capped list of pins, so its totals describe those pins only. Label them as top pin totals, not account totals.
  • Pinterest limits how far back its data goes. If you need year-on-year views, schedule the Profile query into BigQuery or Sheets and report from there.
  • Profile and Top pins do not share a join key, so keep them on separate charts instead of blending them. A "top 10 share of impressions" card is a later add-on.

Suggested Looker Studio page size: 1200 wide, 12 column grid, 14 px gutters, to match the canvas above.
